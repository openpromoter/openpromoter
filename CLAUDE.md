# OpenPromoter

Read `docs/CONTENT-GUIDELINES.md` before writing any copy or changing any design. It holds the owner's
rules: no em dashes, the comma rules, banned words, plain words, flat Apple-style design, square
badges, no motion and no AI art.

Design decisions and their history live in `research/design-v2/DIRECTION.md`.

For every design change, capture before and after screenshots of each changed area and send them to
the owner side by side.

A code graph lives in `graphify-out/` (not committed). Query it with `graphify query "<question>"` before wide
searches, and refresh it after code changes with `graphify update .` (no AI cost).
