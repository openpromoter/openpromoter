# Contributing to OpenPromoter

Thanks for helping. A few things before you open a pull request:

- **Sign the agreement.** Every pull request needs the comment from [CLA.md](CLA.md). It lets us keep the
  SDK, CLI, MCP server and site scripts under MIT and keep the project's license options open.
- **Run the checks.** `pnpm typecheck`, `pnpm lint` and `pnpm test` must pass.
- **Follow the house rules.** Copy and design follow [docs/CONTENT-GUIDELINES.md](docs/CONTENT-GUIDELINES.md).
- **Security issues** go to the address in [SECURITY.md](SECURITY.md), never to a public issue.
